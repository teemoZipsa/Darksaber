# 필드 복각 기준 — 2026-09-13

사용자 결정: “탈출 규칙을 빼고 원작 복각 중심으로 가자.”

## 진단

월드는 2,560×3,200타일이다. 시작 마을에서 인접 마을까지도 수백 타일을 걸어야 하는데,
평상시 이동에 전투용 MOV 제한과 턴 메뉴가 그대로 적용됐다. 먼 마을 생환을 강제하는
규칙이 긴 이동을 필수 과제로 만들고, 획득 보상을 실패 시 취소해 탐험·성장 흐름을 끊었다.
필드의 밝은 캔버스 패널과 어두운 마을 DOM 화면도 시각적으로 분리돼 보였다.

이번 변경의 기준은 가까운 곳을 탐험하고, 싸우고, 얻은 성과를 가지고 마을에 돌아오는
플레이를 성립시키는 것이다. 원작 전체 규칙·맵·연출과의 일치 검증을 끝냈다는 의미는 아니다.

## 적용한 규칙

- 30분 시간 초과 종료를 제거했다. 경과 시간은 기록과 의뢰 보너스 계산에만 사용한다.
- 출발한 마을로 돌아와도 정상 귀환이다. 안전한 필드에는 마을 귀환 버튼을 제공한다.
- 사망, 중도 귀환, 재접속 유예 종료에도 배낭·장비·누적 경험치를 보존한다.
- 달성한 스토리 목표와 획득 보상은 귀환 시 정산한다. 미달성 목표는 완료 처리하지 않는다.
- 소모한 도구, 내구도 감소, 부상은 그대로 유지한다. 보험 구매와 실패 복구 키트 지급은 제거한다.
- 한 번만 지급하는 첫 귀환 보너스는 실제 마을 진입에만 적용한다.

## 이동과 화면

- 적이 없는 야외에서 땅을 클릭하면 경로를 이어 이동한다. 최대 목적지 거리는 128타일이다.
- 이동은 기존 MOV·지형 비용·AP 검증을 통과하는 짧은 명령으로 나누며, 서버 권위를 우회하지 않는다.
- AP 부족 시 기다렸다가 이어 간다. 적 접근, 경로 차단, 서버 거절, 조작 캐릭터 변경 시 중지한다.
- 중지 버튼, Escape, 우클릭, Space로 다음 이동 명령을 취소한다. 이미 승인된 짧은 구간은 마친다.
- 안전한 야외에서는 이동 애니메이션을 빠르게 하고, 매 턴 자동으로 열리던 메뉴를 숨긴다.
- 실내·튜토리얼·전투에서는 기존 전술 조작을 사용한다. 동료 이동은 기존 팡파르 조작을 유지한다.
- React 필드 HUD에 자원·경험치·탐험 상태·의뢰 진행·이동 안내·귀환 버튼을 배치한다.

## 저장 호환성

`RAID_RESULT`, `SURVIVED`, `DEAD`, `MIA`, `LEFT`와 과거 기록의 손실 항목은 기존 저장 및
네트워크 형식의 호환을 위해 유지한다. `limitSeconds`도 과거 snapshot 호환 필드이며 종료 조건이 아니다.
기존 출격 기록은 수정하지 않는다. 새 귀환의 손실 수치는 0이며 획득물과 골드를 기록한다.
진행 중 획득 아이템도 서버 저장 패치에 포함하고, 최종 정산은 기존 서버 flush 경로를 사용한다.
연결 유예는 계속 존재하며, 만료 시 탐험을 정리하고 마을로 돌아가도록 저장한다.

## 카오시아 근교 사냥 동선 — 2026-09-13 후속 개선

- HUD는 남아 있는 첫 구역의 레벨·적 수·거리와 길 안내 버튼을 표시한다. 지도 위의 금색 깃발까지 이동하며, 적 접근 시 기존 전술 조작으로 전환한다.
- 적 수는 현재 필드 상태를 따른다. 다른 플레이어가 먼저 정리한 구역도 반영하고, 추가 보너스나 가상의 퀘스트 완료를 지급하지 않는다.
- 서버는 새 플레이어를 등록하기 전에 초기 배치를 준비한다. 이후 재생성은 기존 5분 대기·화면 밖 생성 규칙과 저장된 nest 상태를 따른다. 재입장으로 즉시 보충되지 않는다.
- 야외 목적지로 향하는 이동은 마을을 지름길로 통과하지 않는다. 마을 안을 직접 클릭한 귀환 경로는 허용한다. 클라이언트와 서버가 같은 판정을 사용한다.
