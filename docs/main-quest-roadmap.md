# 메인퀘스트 로드맵

장기 시나리오 구상은 타르코프식 출격/생환 루프와 분리해서 관리한다. 메인퀘 목표는
위험한 던전 안에서 해결하되, 영구 보상은 반드시 유효한 마을로 생환한 뒤 확정한다.

## V1 구현

| 화 | 퀘스트 id | 진행 공간 | 목표 | 영구 보상 |
|---|---|---|---|---|
| 1 | `main:episode_01_burgos` | `burgos_castle` 던전 | 부르고스성 늑대 보스를 처치한 뒤 다른 마을로 생환 | `quest_bomb` |
| 2 | `main:episode_02_zamora` | `zamora_fortress` 던전 | 자모라 요새의 펜리스를 처치한 뒤 다른 마을로 생환 | 고유 클레릭 동료 |

1화는 새 저장에서 자동 활성화된다. 2화는 1화 완료 후 활성화된다. 저널 상태는
기본 `진행 중`, 보스 처치 후 `목표 달성`, 생환 결과 화면 이후 `완료`로 바뀐다.

## 1-32화 구조

이후 에피소드는 UI에 직접 박지 않고 데이터로 추가한다. 아래는 원작 메인 시나리오
경로를 익스트랙션 RPG 구조에 맞춰 예약해 둔 큰 흐름이다.

| 화 | 적용 패턴 |
|---|---|
| 1-4 | 초반 왕궁 사건, 추적 루트, 초반 던전 보스 목표 |
| 5-8 | 지역 요새/동굴 공략, 마을 서비스 또는 이동 루트 해금 |
| 9-12 | 소문 탭, 마을 NPC 단서, 던전 클리어를 엮은 조사형 목표 |
| 13-16 | 중반 거점 공략, 핵심 적 처치 후 생환을 요구하는 메인퀘 |
| 17-20 | 여러 마을을 잇는 월드맵 이동 목표와 메인 던전 단계 |
| 21-24 | 봉인 구역, 열쇠 아이템, 강화 보스 전투 |
| 25-28 | 최종 지역 준비 퀘스트, 고위험 파밍 루트와 희귀 보상 |
| 29-32 | 최종 던전 연쇄, 결말 보스전, 캠페인 완료 보상 |

## 통합 규칙

- 스토리 문장은 원문 복붙이 아니라 짧게 재작성한 요약으로 둔다.
- 유저에게 보이는 문자열은 `LanguageManager.ts`의 ko/en 양쪽에 추가한다.
- 던전 안에서는 목표 달성만 기록하고, `SURVIVED` 결과 전에는 영구 보상을 주지 않는다.
- 진행에 필요한 보상은 세션 인벤토리가 아니라 `PlayerData.questItems`에 저장한다.
- 공개 전 명칭/에셋 교체는 데이터 파일부터 바꿀 수 있게 유지한다.
